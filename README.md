A Bluetooth keyboard in the form of a slipper (the device is attached to the foot), in some VR games you need to control, and this device sends keystrokes W, S, A, D. I do not know if the author solved the problems of his Bluetooth library, but many years ago it worked poorly, and turned on once a minute. the connection has disappeared, this is the first version of the project, maybe I'll post others later.
the following libraries were used
