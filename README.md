# Bluetooth-keyboard-in-the-form-of-a-slipper
A Bluetooth keyboard in the form of a slipper, in some VR games you need control, and this device sends a key press W,S,A, D. I don't know if the author solved the problems of his Bluetooth library, but many years ago it worked poorly, and once a minute the connection disappeared, this is the first version of the project, maybe later post others.
